## Структура

```
bookshop-project/
├── test-cases/
│   ├── Тест-сьюты_поиска.xlsx       # 24 тест-кейса, 7 тест-сьютов
│   └── Тест-сьюты_корзины.xlsx      # 23 тест-кейса, 5 тест-сьютов
├── api-testing/
│   └── Bookshop_API.postman_collection.json
└── bug-reports/
    ├── bug-report-1.md  — GET /books?string без значения возвращает все книги
    ├── bug-report-2.md  — GET /book/{id} возвращает 204 вместо 404
    ├── bug-report-3.md  — Отсутствует валидация минимального кол-ва символов в поиске
    ├── bug-report-4.md  — Отсутствует валидация максимального кол-ва символов в поиске
    ├── bug-report-5.md  — Фильтры активны при отсутствии результатов поиска
    ├── bug-report-6.md  — POST /review возвращает 500 при отсутствии обязательных полей
    ├── bug-report-7.md  — Ссылка "каталога" в пустой корзине ведёт на /cart
    ├── bug-report-8.md  — Имя автора в корзине ведёт на список авторов вместо страницы автора
    └── bug-report-9.md  — Кнопка "крестик" в модальном окне очищает корзину
```
