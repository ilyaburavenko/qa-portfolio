# BUG-001: GET /books?string без значения возвращает все книги

**Severity:** Minor  
**Priority:** Low  
**Статус:** Open

## Описание
При передаче параметра `string` без значения API возвращает все книги 
вместо пустого массива или сообщения об ошибке.

## Шаги воспроизведения
1. Отправить запрос `GET /books?string`
2. Посмотреть ответ

## Ожидаемый результат
Возвращается пустой массив products [] или ошибка валидации,
так как параметр передан без значения.

## Фактический результат
Возвращаются все книги из базы (12 книг), параметр игнорируется.

## Окружение
- API: http://188.120.241.222:8534
- Метод: GET /books
- Параметр: string (без значения)
