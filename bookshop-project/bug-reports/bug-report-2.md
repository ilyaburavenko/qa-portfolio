# BUG-002: GET /book/{id} возвращает 204 вместо 404 для несуществующего id

**Severity:** Minor  
**Priority:** Medium  
**Статус:** Open

## Описание
При запросе книги с несуществующим id API возвращает 204 No Content
вместо 404 Not Found.

## Шаги воспроизведения
1. Отправить GET /book/99999

## Ожидаемый результат
404 Not Found

## Фактический результат
204 No Content
