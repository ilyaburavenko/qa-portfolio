# BUG-003: Отсутствует валидация минимального количества символов в поиске

**Severity:** Major  
**Priority:** High  
**Статус:** Open

## Описание
При вводе менее 3 символов в строку поиска не появляется красная 
подсказка «Минимальное количество символов 3». Поиск не выполняется, 
но и сообщение об ошибке не отображается — интерфейс никак не реагирует.

## Шаги воспроизведения
1. Открыть http://188.120.241.222/catalog
2. Ввести в строку поиска «Ки» (2 символа)
3. Нажать кнопку лупы

## Ожидаемый результат
Появляется красная подсказка «Минимальное количество символов 3».
Список книг не изменяется.

## Фактический результат
Подсказка не появляется. Поиск не выполняется. 
Интерфейс никак не реагирует на ввод.

## Окружение
- URL: http://188.120.241.222/catalog
- Браузер: Chrome
- Тестовые данные: «Ки» (2 символа), «К» (1 символ)
