# BUG-004: Отсутствует валидация максимального количества символов в поиске

**Severity:** Major  
**Priority:** High  
**Статус:** Open

## Описание
При вводе более 11 символов в строку поиска не появляется красная 
подсказка «Максимальное количество символов 11». Поле принимает 
неограниченное количество символов, поиск выполняется но возвращает 
пустой результат без объяснения причины.

## Шаги воспроизведения
1. Открыть http://188.120.241.222/catalog
2. Ввести в строку поиска «Реаниматорррррррррррррррррррррррррр» (более 11 символов)
3. Нажать кнопку лупы

## Ожидаемый результат
Появляется красная подсказка «Максимальное количество символов 11».
Поиск не выполняется. Список книг не изменяется.

## Фактический результат
Подсказка не появляется. Поле принимает любое количество символов.
Поиск выполняется, возвращает сообщение «По вашему запросу ничего 
не нашлось» без указания причины.

## Окружение
- URL: http://188.120.241.222/catalog
- Браузер: Chrome
- Тестовые данные: «Реаниматорррррррррррррррр» (более 11 символов)
