# BUG-005: Фильтры и сортировка доступны при отсутствии результатов поиска

**Severity:** Minor  
**Priority:** Medium  
**Статус:** Open

## Описание
При поисковом запросе который не возвращает результатов фильтры 
по цене и сортировка остаются активными и доступны для взаимодействия.
По ТЗ они должны быть заблокированы.

## Шаги воспроизведения
1. Открыть http://188.120.241.222/catalog
2. Ввести запрос который не даёт результатов (например «Реаниматорррррр»)
3. Нажать кнопку лупы
4. Проверить состояние фильтров и сортировки

## Ожидаемый результат
Сортировка и фильтры по цене заблокированы (недоступны для 
взаимодействия).

## Фактический результат
Сортировка и фильтры по цене активны — можно выбрать сортировку 
«По убыванию цены» и применить фильтр по цене несмотря на отсутствие 
результатов.

## Окружение
- URL: http://188.120.241.222/catalog
- Браузер: Chrome
