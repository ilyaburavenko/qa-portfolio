# BUG-008: Имя автора в корзине ведёт на список авторов вместо страницы автора

**Severity:** Minor  
**Priority:** Medium  
**Статус:** Open

## Описание
Имя автора в корзине должно быть ссылкой на детальную страницу конкретного автора.
Фактически ссылка ведёт на общий список авторов /authors.

## Шаги воспроизведения
1. Добавить любую книгу в корзину
2. Открыть /cart
3. Нажать на имя автора книги

## Ожидаемый результат
Переход на детальную страницу конкретного автора

## Фактический результат
Переход на общий список авторов /authors

## Требование
Раздел "Элементы": имя автора — ссылка, ведущая на детальную страницу автора книги
