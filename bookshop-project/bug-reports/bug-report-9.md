# BUG-009: Кнопка "крестик" в модальном окне очищает корзину

**Severity:** Major  
**Priority:** High  
**Статус:** Open

## Описание
Кнопка "крестик" должна закрывать модальное окно без очистки корзины.
Фактически при нажатии крестика корзина очищается — поведение 
идентично кнопке "Ок".

## Шаги воспроизведения
1. Добавить товары в корзину
2. Нажать "Оформить заказ"
3. В модальном окне нажать крестик

## Ожидаемый результат
Модальное окно закрывается. Товары в корзине остаются.

## Фактический результат
Модальное окно закрывается. Корзина очищается.

## Требование
п.5 раздела "Элементы": кнопка "крестик" закрывает модальное окно, 
но не очищает корзину.
