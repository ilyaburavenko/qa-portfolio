# ForwardTest — Тестовое задание Junior QA

Тестирование десктопного приложения **ForwardTest.exe** — симулятора дорожного движения.  
Метод тестирования: **чёрный ящик**.

---

## Задание

Перед разработчиками стояли требования:
- ТС умеет перемещаться по дороге, управление через стрелки клавиатуры
- Дорога имеет по одной полосе с каждой стороны, разделённых сплошной линией с разрывами
- В месте разрыва разрешён разворот без нарушений ПДД
- Программа контролирует: выезд на встречную полосу и пересечение сплошной линии
- При нарушениях выводится соответствующее сообщение
- При нескольких одновременных сообщениях все они видны пользователю
